## Requirements
### Requirement: Interfaz de usuario para hibridación
El sistema SHALL proporcionar una interfaz web para seleccionar arreglistas y ejecutar la hibridación.

#### Scenario: Visualización de resultados de hibridación
- **WHEN** el usuario selecciona dos arreglistas y ejecuta la hibridación
- **THEN** la interfaz muestra el perfil resultante y el log de resoluciones
